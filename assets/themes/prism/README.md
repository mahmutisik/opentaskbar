# Prism

Prism is a graphite and violet-accented color and widget theme for OpenTaskbar.

It styles the dock, menus, settings and widgets **without replacing Windows or application icons**. Existing installations with Prism's old icon files also keep their original icons.

## Install

1. Select **Prism** in **Settings → Appearance → Theme pack**.
2. Restart OpenTaskbar to apply the font and corner-size changes.

See [Theme Packs](../../docs/themes.md) for custom theme options.
